CampusAssist Documentation
CampusAssist is a full-stack university management and collaboration platform for Students, Teachers, and Admins. It centralizes announcements, class routine, results, free classrooms, smart classrooms, resources, study groups, deadlines, consultations, bus schedules, notifications, profile management, assignments, and admin user management. The current implementation follows a 3-tier architecture shown across README.md, frontend/src/App.js, backend/server.js, and backend/routes/index.js.

Architecture

Presentation layer: React frontend in frontend/src
Application layer: Node.js + Express REST API in backend
Data layer: PostgreSQL schema and seed data in schema.sql and schema_additions.sql
Design patterns used:
MVC: components + controllers + repositories
Singleton: PostgreSQL pool in database.js
Repository Pattern: backend/repositories/index.js
Factory Pattern: backend/services/UserFactory.js
Observer-style notification handling: backend/services/NotificationService.js

Important Algorithms

Free classroom detection:
compares all rooms with occupied rooms for a given day/time
Recommendation engine:
score = downloads 0.5 + rating 0.3 + recency 0.2
Routine parsing:
imports CSV routines and converts them into structured timetable data
Attendance and marks aggregation:
smart classroom endpoints summarize per-student records

Viva-Ready Explanation
If asked “What is CampusAssist?”:

CampusAssist is a full-stack university management and collaboration platform that unifies academic communication, classroom coordination, resources, results, deadlines, study groups, consultations, and administration into one role-based system.
If asked “Why these technologies?”:

React gives reusable UI and fast client-side interaction.
Express gives a simple REST API structure.
PostgreSQL is strong for relational academic data and complex queries.
JWT supports stateless authentication.
Tailwind and MUI together help build responsive and polished interfaces.
Repository and Singleton patterns improve maintainability and database control.
If asked “What makes it smart?”:

free classroom detection
recommendation scoring for resources
smart classroom attendance and marks tracking
role-based workflows for students, teachers, and admins
